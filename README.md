# 🎤 L'histoire du rap

Bienvenue sur mon site consacré à **l'histoire du rap**.

## 📚 Présentation

Ce site a été réalisé dans le cadre d'un projet scolaire de niveau seconde.
Il présente :

- les origines du rap à New York ;
- l'évolution du hip-hop ;
- l'arrivée et le développement du rap en France ;
- quelques artistes importants ;
- les quatre grands éléments de la culture hip-hop ;
- un petit quiz.

## 🛠️ Technologies utilisées

- HTML
- CSS
- JavaScript

## ▶️ Ouvrir le site

Pour ouvrir le site sur un ordinateur, il suffit d'ouvrir le fichier :

`index.html`

Les fichiers `index.html`, `style.css` et `script.js` doivent rester dans le même dossier.
